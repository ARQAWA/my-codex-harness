# Системный промпт

Codex-части заморожены до прямой разморозки владельцем; процедуры для них
ниже сохраняются как архивный baseline и не выполняются.
Общий статус и границы установки: [INSTALL_FOR_AGENTS.md](../INSTALL_FOR_AGENTS.md).

## Состав

[`new-model-instructions.md`](../new-model-instructions.md) в корне репозитория
содержит общие правила поведения модели. Это отдельный компонент поставки,
подключаемый через `model_instructions_file` вместо встроенных инструкций.
Он не входит в пакеты плагинов и не требует кастомного каталога моделей.

Версия промпта определяется source commit. Промпт самодостаточен: работает
без плагинов и других механик harness, не содержит ссылок на конкретные
плагины, их workflows, состояние или файлы. Goal, Notebook, cleanup и
маршрутизация задаются соответствующими плагинами отдельно и не переносятся
в базовый промпт. Общие правила использования доступных инструментов
не требуют их установки.

## Требования

Нужен Codex с поддержкой `model_instructions_file` и доступ к активному
Codex home. Поддерживаются macOS, Linux и Windows; в Windows используй
только Git Bash. Не переноси абсолютные пути с другой машины.

## Первая установка

Определи активный Codex home и используй исходник выбранной ревизии репозитория.
Если `model_instructions_file` уже задан, выполни раздел обновления.
Иначе скопируй исходник без изменения текста в
`<active-codex-home>/new-model-instructions.md`. В корневой части активного
`config.toml`, до таблиц, задай один ключ с реальным абсолютным путём:

```toml
model_instructions_file = "<абсолютный путь к установленному new-model-instructions.md>"
```

Копирование и настройку выполняет устанавливающий агент. В Windows используй
пути с `/` либо корректные TOML literal strings. Сохрани остальные настройки;
каталог моделей и версию субагентов эта инструкция не меняет.
Для применения настроек перезапусти Codex и начни новую задачу.
Не прерывай текущую задачу автоматическим перезапуском.

## Проверка после установки

Сравни исходник и установленную копию: содержимое должно совпадать дословно.
Прочитай `config.toml`: единственный `model_instructions_file` должен указывать
на доступную постоянную копию. Запуск моделей и пробных задач не требуется.

## Обновление

Обнови копию из выбранной ревизии по уже настроенному пути
`model_instructions_file`, не меняя этот путь и остальные настройки.
Если ключ отсутствует, выполни первую установку. Совпадающий файл повторно
не записывай. Выполни проверку выше; после изменения файла или настройки
перезапусти Codex и начни новую задачу, не прерывая текущую автоматически.
