# Системный промпт

Общий статус и границы установки: [INSTALL_FOR_AGENTS.md](../INSTALL_FOR_AGENTS.md).

## Состав

[`new-model-instructions.md`](../new-model-instructions.md) в корне репозитория
содержит оригинальные базовые инструкции GPT-5.5 из `openai/codex`
(`codex-rs/models-manager/models.json`, запись `gpt-5.5`) без пяти вырезов:
раздела «Frontend guidance», упоминания `multi_tool_use.parallel`, пункта о
расширении тестов, предложения «suggest follow ups» и пункта об обновлениях
«every 30s». Это отдельный компонент поставки, подключаемый через
`model_instructions_file` вместо встроенных инструкций. Он не входит в пакеты
плагинов и не требует кастомного каталога моделей.

Версия промпта определяется source commit. Промпт самодостаточен: работает
без плагинов и других механик harness и не ссылается на плагины, их workflows,
состояние или файлы; инструменты Codex (`rg`, `apply_patch`, `exec_command`) он
называет так же, как оригинал. Рабочие принципы, todo-список, Goal, review и
субагентов задаёт Scope Focus поверх него; без Scope Focus модель работает по
инструкциям GPT-5.5.

## Требования

Нужен Codex с поддержкой `model_instructions_file` и доступ к активному
Codex home. Поддерживаются macOS, Linux и Windows; в Windows используй
только Git Bash. Не переноси абсолютные пути с другой машины.

Агенты ищут по коду через `rg` (ripgrep) в командной оболочке; права
администратора не нужны. Запасной путь без отдельной установки — поиск Git
(`git ls-files`, `git grep`).

## Первая установка

Определи активный Codex home и используй исходник выбранной ревизии репозитория.
Если `model_instructions_file` уже задан, выполни раздел обновления.
Иначе скопируй исходник без изменения текста в
`<active-codex-home>/new-model-instructions.md`. В корневой части активного
`config.toml`, до таблиц, задай один ключ с реальным абсолютным путём:

```toml
model_instructions_file = "<абсолютный путь к установленному new-model-instructions.md>"
```

Копирование и настройку выполняет устанавливающий агент. В Windows используй
пути с `/` либо корректные TOML literal strings. Сохрани остальные настройки;
каталог моделей и версию субагентов эта инструкция не меняет.
Для применения настроек перезапусти Codex и начни новую задачу.
Не прерывай текущую задачу автоматическим перезапуском.

Поиск. Выполни `rg --version` через командный инструмент harness агента,
в Windows — в Git Bash. Многие harness поставляют свой `rg`; если команда
работает, ничего не меняй. Иначе:

- macOS: `brew install ripgrep`, если есть Homebrew.
- Windows без прав администратора: найди готовый `rg.exe`, который
  поставляется, например, с VS Code или Cursor, либо возьми скачанный
  владельцем официальный архив `ripgrep-*-x86_64-pc-windows-msvc.zip`:

  ```bash
  find "$(cygpath "$LOCALAPPDATA")/Programs" "$(cygpath "$PROGRAMFILES")" \
    "$(cygpath "$USERPROFILE")/.vscode/extensions" \
    "$(cygpath "$USERPROFILE")/.cursor/extensions" -name rg.exe 2>/dev/null
  ```

  Скопируй `rg.exe` в `~/bin`. Если `~/bin` нет в `PATH` Git Bash, добавь
  в `~/.bashrc` строку `export PATH="$HOME/bin:$PATH"`.

Если `rg` получить нельзя, сообщи владельцу.

## Проверка после установки

Сравни исходник и установленную копию: содержимое должно совпадать дословно.
Прочитай `config.toml`: единственный `model_instructions_file` должен указывать
на доступную постоянную копию. Запуск моделей и пробных задач не требуется.

Выполни `rg --version` через командный инструмент harness агента, в Windows —
в Git Bash. Если `rg` недоступен, сообщи владельцу, что поиск пойдёт через Git.

## Обновление

Обнови копию из выбранной ревизии по уже настроенному пути
`model_instructions_file`, не меняя этот путь и остальные настройки.
Если ключ отсутствует, выполни первую установку. Совпадающий файл повторно
не записывай. Выполни проверку выше; после изменения файла или настройки
перезапусти Codex и начни новую задачу, не прерывая текущую автоматически.
Если `rg` недоступен, сначала выполни шаги «Поиск» из первой установки.
