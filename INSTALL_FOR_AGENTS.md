# Инструкции установки для агентов

Это единая точка входа для установки и обновления компонентов репозитория.
Используй точную выбранную ревизию и инструкции только заказанных компонентов.
Источники действий установки — этот документ, выбранная инструкция и её явно
указанные зависимости. Репозиторный `AGENTS.md` описывает разработку, находится
вне процедуры установки и не является источником её дополнительных шагов.
Полный release выбранных компонентов включает локальную установку на текущем
хосте после source/push/publication из тех же подготовленных локальных файлов,
без обратного скачивания своего release. Только публикация выполняется по явному
частичному заказу. Уже подготовленные совместимые зависимости переиспользуй.
Остальные компоненты автоматически не устанавливай.

| Компонент | Инструкция |
|---|---|
| Scope Focus | [`install-instructions/scope-focus.md`](install-instructions/scope-focus.md) |
| Системный промпт Codex | [`install-instructions/system-prompt.md`](install-instructions/system-prompt.md) |

Системный промпт — отдельный компонент, подключаемый через
`model_instructions_file` в Codex. Правила работы, роли и review даёт Scope
Focus, поэтому полный harness — оба компонента. Каталог моделей определяет
штатный Codex. Прямой `codex plugin add` сам по себе не выполняет инструкции
репозитория.

После установки или обновления выбранных компонентов выполни зачистку следов
прежних версий по [`LEGACY-CLEANUP.md`](LEGACY-CLEANUP.md) той же ревизии, в том
же заказе и без отдельной просьбы. Явный запрет владельца на зачистку отменяет
этот шаг.

После выбранного документа и зачистки сообщи установленную ревизию, пути
компонентов, изменения настроек, проверки, удалённые следы прежних версий,
оставленные объекты с причиной и оставшиеся блокеры.
