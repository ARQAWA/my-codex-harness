# Инструкции установки для агентов

Это единая точка входа для установки и обновления плагинов из этого репозитория.
Используй точную выбранную ревизию репозитория. Сначала прочитай корневой
`AGENTS.md`, затем выбери ровно один основной plugin из запроса и выполни его
инструкцию. Документы других плагинов разрешено читать и выполнять только в
части явно объявленных обязательных зависимостей выбранного plugin. Уже
подготовленные совместимые зависимости переиспользуй. Остальные функции и
полную установку другого плагина автоматически не запускай.

| Plugin | Инструкция |
|---|---|
| `scope-focus` | [`install-instructions/scope-focus.md`](install-instructions/scope-focus.md) |
| `lunatron` | [`install-instructions/lunatron.md`](install-instructions/lunatron.md) |
| `filesystem-search` | [`install-instructions/filesystem-search.md`](install-instructions/filesystem-search.md) |

`config/INSTALL.md`
отдельно описывает каталог моделей и общие инструкции для моделей; он не является
инструкцией установки плагинов. Прямой `codex plugin add` сам по себе не
выполняет инструкции репозитория.

После выбранного документа сообщи установленную ревизию, путь плагина,
изменения tooling/config, проверки и оставшиеся блокеры.
