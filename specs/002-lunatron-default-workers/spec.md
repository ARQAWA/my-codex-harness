# Спецификация: рабочие форки Lunatron по умолчанию

**Статус:** согласовано

## Что должно измениться

В новом корневом чате Lunatron уже активен. Если задаче нужен исполнитель,
Main запускает его без команды `LNT1`. Команда `LNT0` по-прежнему выключает
режим текущего чата.

## Сценарии

1. Пользователь даёт рабочую задачу в новом чате. Main передаёт связный
   блок подходящему исполнителю без ручного включения Lunatron.
2. Main на Sol Medium разбирает сложную задачу. Рабочий форк — Sol Medium.
   Простой блок — Luna Medium.
3. Main на Sol Medium поручает разбор выбранного лога. Luna Extra High не
   запускается: простой вопрос получает Luna Medium, сложный блок — Sol Medium.
4. Main на Luna поручает сложный блок. Форк использует ту же модель Luna
   с `xhigh`.

## Требования

- **FR-01.** Инструкции, действующие в новом чате, разрешают рабочее
  делегирование при `LUNATRON_STATE=ACTIVE`. Отдельная команда `LNT1` не нужна.
- **FR-02.** Для простого блока используется `gpt-6-luna/medium`.
  Это относится и к узкому вопросу по выбранным большим данным.
- **FR-03.** Для сложного блока модель и effort выбираются по таблице.

| Main | Сложный рабочий форк |
| --- | --- |
| Sol ниже `high` | Та же точная Sol, тот же effort |
| Sol `high` и выше | Та же точная Sol, `high` |
| Astra ниже `high` | `gpt-6-sol`, тот же effort |
| Astra `high` и выше | `gpt-6-sol/high` |
| Luna, любой effort | Та же точная Luna, `xhigh` |

- **FR-04.** Luna `xhigh` запускается только для сложного рабочего блока,
  когда Main — Luna. Профиль Luntik не создаёт исключения.
- **FR-05.** Если действующее правило более высокого уровня запрещает
  нужный форк, Main сообщает о конфликте и не выполняет этот блок скрыто
  вместо исполнителя.
- **FR-06.** Правила для явно заказанного review остаются отдельными:
  reviewer не считается рабочим форком Lunatron.

## Критерии готовности

- **SC-01.** Новый чат с активным Lunatron делегирует рабочий блок без `LNT1`.
- **SC-02.** При Main Sol Medium простой блок получает Luna Medium, сложный —
  Sol Medium; ни один из них не получает Luna Extra High.
- **SC-03.** При Main Luna Low сложный блок получает Luna `xhigh`.
- **SC-04.** При Main Sol Max сложный блок получает Sol High; при Astra Max —
  Sol High.
- **SC-05.** После `LNT0` новые рабочие форки Lunatron не запускаются.
