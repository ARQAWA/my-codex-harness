Настройка каталога моделей Codex на другом компьютере

1. Найдите существующую папку настроек Codex на своём компьютере.
2. В папке config этого репозитория найдите файлы
   codex-model-catalog.json и new-model-instructions.md.
3. Скопируйте оба файла в папку настроек Codex.
4. Откройте файл конфигурации Codex.
5. В параметре model_catalog_json укажите копию файла каталога моделей
   из папки настроек Codex.
6. В параметре model_instructions_file укажите копию файла системного
   prompt из папки настроек Codex.
7. Сохраните файл конфигурации и перезапустите Codex.
   Уже запущенная задача не перечитывает каталог автоматически.

В каталоге пусты только основные промпты: base_instructions и
model_messages.instructions_template. Свой основной промпт задайте через
model_instructions_file. Служебные инструкции взяты из Astra 0.153.4
и одинаковы у всех четырёх моделей.

Временно отменённый пункт: экспериментальное управление контекстом

Пока не включайте context_management в экспериментальном режиме.
Этот пункт временно исключён из установки: поведение функции пока неясно.
Ранее здесь предлагалось добавить следующую настройку. Сейчас не добавляйте её:

[features.context_management]
experimental_mode = true
