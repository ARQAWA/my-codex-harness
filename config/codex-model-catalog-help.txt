Каталог моделей и инструкции Codex

codex-model-catalog.json задаёт модели и их возможности.
new-model-instructions.md задаёт общие правила работы агента.

Подключи оба файла к Codex из пользовательской папки .codex.
Способ подключения выбери для текущей системы; в Windows используй Git Bash.
Сохрани остальные настройки. Новые инструкции относятся к задачам,
начатым с обновлёнными настройками.

В каталоге видны Astra, GPT-5.5, Sol, Terra и Luna. Служебные модели скрыты.
У каждой модели сохранены её особенности, уровни рассуждения, ускоренный
режим и лимиты. Общие возможности работы с инструментами взяты у Astra.
