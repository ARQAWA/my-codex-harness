# Set up Context Management

Before installation or configuration, read [install.md](../../install.md)
completely. Resolve the link relative to this `SKILL.md`, not the working
directory. Use that file as the installation procedure and path/config source;
do not reconstruct its commands from memory.

For a user-authorized installation, follow the applicable new-install or
existing-install sequence in install.md, preserving current settings, data, and
unrelated MCP/configuration. Check the required harness capabilities first;
report a concrete incompatibility instead of claiming setup succeeded.
Registration with `codex plugin add` alone is not runtime activation. Finish
only after the documented activation result is obtained. For explanation-only
requests, explain the procedure without changing files.
