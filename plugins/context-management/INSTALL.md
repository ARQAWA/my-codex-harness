# Установка

Плагин содержит `memory.js`, skill и Node.js hooks. Он работает из своей
установленной папки и хранит базу и настройки в одной пользовательской папке.
Нужен Node.js 24.5 или новее. MCP и PowerShell не нужны; в Windows используется
Git Bash.

При установке подключи сам плагин и его встроенные hooks в пользовательском
Codex. Отдельно включи штатный TokenBudget и переход в новое окно контекста.
Первая установка готова, когда агент может сохранить checkpoint и восстановить
его вместе со ссылкой на точную запись истории.

При обычном обновлении замени файлы плагина целиком, но сохрани существующую папку данных,
SQLite-базу, настройки и секреты на прежних местах. Миграция базы выполняется при
первом обычном обращении к `memory.js`. Уже открытые задачи используют инструкции,
которые были загружены при их запуске.
