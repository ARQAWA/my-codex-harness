# Установка

## Состав

В пакете находятся программа памяти `memory.js` и skill `local-context-memory`.
Они работают прямо из установленного плагина. Нужен Node.js 24.5 или новее.
Вне пакета допустима одна папка пользователя для базы, журналов и настроек.

## Первая установка

Установи пакет в пользовательский `.codex`. Подключи управление бюджетом
контекста в Codex и свяжи его подсказки со skill этого пакета. Для полного цикла
Codex должен поддерживать переход в новое окно контекста. Готовность означает,
что агент может сохранить и восстановить контекст через установленный плагин.
Способ работы выбери для текущей системы; в Windows используй Git Bash.

## Обновление

Обнови пакет и ссылки на его текущие файлы в настройках Codex. Код и skill
должны оставаться внутри пакета, без отдельных внешних копий. При переходе со
старой установки убери такие копии после подключения файлов плагина. Сохрани
существующую папку данных, базу и остальные настройки. Прочитай изменённый
результат; полную проверку первой установки без запроса не повторяй.
Уже открытые задачи сохраняют ранее загруженные инструкции.
