# Установка

## Состав

В пакете находятся правила работы, hooks, skills и профиль проверяющего
`properliler` — `agents/properliler.toml`. Этот профиль отдельно подключается
в общем каталоге агентов Codex.

## Первая установка

Установи пакет в пользовательский `.codex` и подключи профиль проверяющего.
Доверие к hooks настрой штатным способом. Напоминание для Sol по умолчанию
выключено, если пользователь не попросил его включить. Готовность означает,
что skills, профиль и все hooks работают в настоящей среде Codex.
Способ работы выбери для текущей системы; в Windows используй Git Bash.

## Обновление

Обнови пакет и отдельно установленный профиль из одной версии. Сохрани
остальные профили, настройки и данные. Доверие к hooks уточняй только при
изменении их определений или по запросу Codex. Прочитай изменённый результат;
полную проверку первой установки без запроса не повторяй. Уже открытые задачи
сохраняют ранее загруженные инструкции.
