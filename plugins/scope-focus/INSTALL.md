# Установка

## Состав

Пакет содержит правила работы, hooks, skills и профиль проверяющего
`agents/properliler.toml`. Task Notebook хранит план и прогресс длительной
задачи при явном выборе пользователя. Goal Memory заменён этим skill.

## Требования

Нужны Codex с поддержкой плагинов и hooks, Node.js и отдельно подключённый
профиль `properliler`. Поддерживаются macOS, Linux и Windows; в Windows
используется только Git Bash, без PowerShell.

## Первая установка

Установи пакет штатным механизмом Codex, включи его hooks и подключи
`properliler` из этого пакета в общем каталоге агентов. Напоминание для Sol
по умолчанию выключено; включай его только по запросу пользователя.

Настрой доверие к hooks через штатный Codex app-server. Получи определения
через `hooks/list` и запиши нужный trust через `config/batchWrite` в
`hooks.state`: используй точный ключ hook и его `currentHash` как
`trusted_hash`. Меняй только hooks устанавливаемого плагина; уже доверенные
не переписывай. Не обходи trust и не подставляй хеш из прежней версии.

## Проверка после установки

В конце установки устанавливающий агент проверяет подключённые части,
состояние trust и работу всех зарегистрированных hooks на целевой ОС.
В Windows выполняй эту проверку на Windows через Git Bash; запуск на macOS
или Linux не подтверждает работу Windows. Проверяй штатные события Codex,
включая предусмотренное отключение необязательных функций.

Готовность означает, что skills доступны, профиль проверяющего подключён,
a hooks передают предусмотренные инструкции. Наличие Task Notebook не
активирует его без выбора пользователя.

## Обновление

Обнови пакет и отдельно установленный `properliler` из одной версии.
Сохрани остальные профили, настройки, notebook и данные. Через app-server
согласуй trust изменённых hook-определений; затем выполни раздел проверки
для обновлённых частей. Полную проверку первой установки без запроса не
повторяй. Новые инструкции загружаются в новой задаче; открытые задачи могут
сохранять прежний контекст.
