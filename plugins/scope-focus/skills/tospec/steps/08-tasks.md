# 08. Задачи

Вход: точная проверенная версия plan.md. Теперь прочитай
[шаблон задач](../templates/tasks.md) и создай tasks.md в том же OS tmp workspace.

Разложи план в необходимый порядок конкретных исполнимых действий T. Для каждого
укажи P-блок плана, область/файлы, зависимости, действие, ожидаемый результат и
достаточную проверку. Ссылки на R/AC сохраняй через план без пересказа спеки.
Следуй полным Working Standards; одна простая работа не требует искусственных фаз,
ролей, параллельных писателей одних файлов или собственного scheduler.

Задачи не являются новым проектированием. Если для T нужно решение, которого
нет в плане, внеси его в план и пройди его gate заново до зависимых задач.
Если оно меняет спеку — вернись к 02–05. Иначе решай внутри полномочий агента,
не запрашивая approval плана или задач. Не добавляй «заодно» тесты, документы,
cleanup, улучшения или проверки без предусмотренного стандартом основания.

Не оставляй задач с неопределённым действием, непроверенным обязательным путём,
нерешённой зависимостью или будущим выбором способа. Предлагаемый новый файл
отмечай «создать». Не называй будущие действия выполненными.

Выход: конкретные задачи полностью покрывают проверенный план и ничего сверх него.
Укажи точную версию плана; задачи пока `ЧЕРНОВИК`. Далее `09-tasks-review.md`.
