# 07. Gate плана

Примени [порядок review](../references/review.md), `review_stage=pre-action`.
Объект: plan.md; основания: согласованная spec.md, решающие факты проекта и полный
Working Standards. Задачи ещё не создаются и не требуются для этого checkpoint.

Проверь соответствие всех блоков плана спеке, полноту R/AC, отсутствие лишней
работы, неявного изменения утверждённых условий, ложных фактов и нерешённых
инженерных выборов. Поручи проверить каждый применимый пункт стандарта, в том
числе самый простой достаточный способ, переиспользование и теоретическую
обоснованность эффективности без требования эмпирических доказательств.

Исправления выполняет агент по общему циклу. Утверждённую спеку под ошибочный
план не подгоняй. При необходимости изменить её вернись к согласованию спеки.

Выход: CLEAN по текущей версии плана и указанной версии спеки. Запиши gate и
статус плана `ПРОВЕРЕН`; далее `08-tasks.md`. Пользовательское approval не нужно.
