# Установка

## Состав

Пакет содержит четыре hook-определения, контракт Main, Node.js CLI для
подготовки контекста и профили
`agents/lunatik.toml` и `agents/luntik.toml`. Lunatik выполняет точные поручения
и пишет элементарный код по конкретному образцу. Luntik готовит факты и точные
места для чтения. Рабочие команды остаются у Lunatik; собственные сложные
патчи Main пишет и применяет напрямую. Main запускает слепую проверку готового крупного блока
и принимает результат. Для проверки отдельно нужен properliler из Scope Focus.
Инструмент читает большие источники на стороне Luna и собирает компактный
ответ с точными фрагментами. Он не вызывает отдельные модели, не пишет файлы
и не исполняет команды. Зависимостей npm нет. Поддерживаются macOS, Linux
и Windows; в Windows используется только Git Bash, без PowerShell.

## Первая установка

Нужны Node.js, оба профиля помощников, подключённый properliler и доверие
к текущим hook-определениям. Контракт Main сообщает актуальный путь CLI; Main
передаёт его помощникам. Первая установка готова, когда доступны оба
помощника и properliler, а все четыре hook-определения активны. Способ
подключения определяется по составу пакета и текущей системе.

Перехват плагина действует на результаты, которые host передаёт в PostToolUse.
Он сохраняет большой ответ в файл и выдаёт Main короткий статус и путь.
Guard действует только на Main; собственный вывод помощников им не ограничен.
Они возвращают Main один краткий итог с существенными фактами, ошибками и
неизвестным. Все каналы сообщений V2 этот перехват не охватывает.
Исходники и изменение самого Codex для установки не нужны.
Lunatron и Tritron не должны работать одновременно.

## Обновление

Обновляются пакет, его CLI и оба профиля помощников. Все части Lunatron должны быть
одной актуальной версии. properliler подключается из своего пакета отдельно.
Сохраняются настройки, данные, сохранённые результаты, артефакты и остальные
плагины. Новые инструкции загружаются в новой задаче; открытая задача может
сохранять прежний контекст. Обычное обновление не запускает проверки первой
установки автоматически.
