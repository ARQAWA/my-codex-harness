# Установка

## Состав

Пакет содержит четыре hook-определения, контракт Main, Node.js CLI для
подготовки контекста и профили `agents/lunatik.toml` и `agents/luntik.toml`.
Lunatik выполняет рабочие команды и простые правки по точному поручению.
Luntik готовит факты и ссылки на исходники. Main владеет решениями, своими
сложными патчами и приёмкой. CLI извлекает фрагменты для ответа Main;
он не вызывает модели, не пишет файлы и не исполняет команды.

## Требования

Нужны Codex с поддержкой плагинов и hooks, Node.js, оба профиля помощников
и отдельно подключённый `properliler` из Scope Focus. Зависимостей npm нет.
Поддерживаются macOS, Linux и Windows; в Windows используется только Git
Bash, без PowerShell. Lunatron и Tritron не должны работать одновременно.

## Первая установка

Установи пакет штатным механизмом Codex, включи его hooks и подключи оба
профиля помощников из этого пакета в общем каталоге агентов. Подключи
`properliler` из Scope Focus. Контракт Main сообщает путь bundled CLI,
который Main передаёт помощникам. Исходники Codex для установки не нужны.

Настрой доверие к hooks через штатный Codex app-server. Получи определения
через `hooks/list` и запиши нужный trust через `config/batchWrite` в
`hooks.state`: используй точный ключ hook и его `currentHash` как
`trusted_hash`. Меняй только hooks устанавливаемого плагина; уже доверенные
не переписывай. Не обходи trust и не подставляй хеш из прежней версии.

## Проверка после установки

В конце установки устанавливающий агент проверяет подключённые части,
состояние trust и работу всех зарегистрированных hooks на целевой ОС.
В Windows выполняй эту проверку на Windows через Git Bash; запуск на macOS
или Linux не подтверждает работу Windows. Проверяй штатные события Codex,
включая предусмотренное отключение необязательных функций.

Готовность означает, что оба помощника и properliler доступны, а четыре
hook-определения активны. Guard ограничивает только поддерживаемые ответы
Main; вывод помощников им не ограничен. Полный перехват всех сообщений V2
не обеспечивается и не является заявленной возможностью.

## Обновление

Обнови пакет, его CLI и оба профиля помощников из одной версии. Профиль
`properliler` обновляется из Scope Focus отдельно. Сохрани настройки, данные,
сохранённые результаты, артефакты и остальные плагины. Через app-server
согласуй trust изменённых hook-определений; затем выполни раздел проверки
для обновлённых частей. Полную проверку первой установки без запроса не
повторяй. Новые инструкции загружаются в новой задаче; открытые задачи могут
сохранять прежний контекст.
