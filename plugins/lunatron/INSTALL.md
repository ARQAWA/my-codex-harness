# Установка

## Состав

Пакет содержит четыре hook-определения, контракт Main и профили
`agents/lunatik.toml` и `agents/luntik.toml`. Lunatik выполняет точные поручения
и пишет элементарный код по конкретному образцу. Luntik готовит факты и точные
места для чтения. Main запускает слепую проверку готового крупного блока
и принимает результат. Для проверки отдельно нужен properliler из Scope Focus.

## Первая установка

Нужны Node.js, оба профиля помощников, подключённый properliler и доверие
к текущим hook-определениям. Первая установка готова, когда доступны оба
помощника и properliler, а все четыре hook-определения активны. Способ
подключения определяется по составу пакета и текущей системе.

Перехват плагина действует на результаты, которые host передаёт в PostToolUse.
Он сохраняет большой ответ в файл и выдаёт Main короткий статус и путь.
Исходники и изменение самого Codex для установки не нужны.
Lunatron и Tritron не должны работать одновременно.

## Обновление

Обновляются пакет и оба профиля помощников. Все части Lunatron должны быть
одной актуальной версии. properliler подключается из своего пакета отдельно.
Сохраняются настройки, данные, сохранённые результаты, артефакты и остальные
плагины. Новые инструкции загружаются в новой задаче; открытая задача может
сохранять прежний контекст. Обычное обновление не запускает проверки первой
установки автоматически.
